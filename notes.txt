CMakePresets.json is where the cool kids live

it seems that "binaryDir" is defunct: the default is to build to ${sourceDir}/out/build/${presetName}
-- I concluded that from having a preset entry which omitted the binaryDir folder, and lo and behold the presetName folder was
created exactly where I thought it would be

in order for LeapC.h to be found, I MUST provide an environment property containing a property named "LEAP_SDK":

"environment": {
  "LEAP_SDK": "${sourceDir}/../../LeapDeveloperKit/LeapDeveloperKit_4.1.0+52211_win/LeapSDK"
}

this still leaves us without binaries: running cannot currently find OgreMain_d.dll for example (and others obviously)+
